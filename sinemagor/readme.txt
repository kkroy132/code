AI-powered movie review generator with TMDB integration and OpenRouter.

== Description ==

Sinemagor discovers movies via the TMDB API, lets you curate a library, and
generates AI-written reviews (via OpenRouter) that publish as WordPress posts.
Includes bulk generation, internal linking, IndexNow submission, post-health
monitoring, and comparison/list-post tools.

== Installation ==

1. Upload the `sinemagor` folder to `/wp-content/plugins/`.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Go to Sinemagor → Settings and add your TMDB API key and OpenRouter API key.

== Frequently Asked Questions ==

= Do I need API keys? =

Yes — a TMDB API key (free) for movie data and an OpenRouter API key for AI
review generation.
