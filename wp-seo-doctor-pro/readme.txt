Unlimited link suggestions, extra redirect types, Search Console insights, and AI assistance for WP SEO Doctor.

== Description ==

WP SEO Doctor Pro is an add-on for the free
[WP SEO Doctor](https://wordpress.org/plugins/wp-seo-doctor/) plugin —
it requires that plugin to be installed and active, and is not sold or
distributed through WordPress.org.

= What Pro adds =

* **Unlimited internal-link suggestions** (Free is capped at 25/month).
* **Extra redirect types** — 307, 308, and 410, alongside Free's 301/302.
* **Google Search Console integration** — an SEO Opportunity Finder
  (pages ranking just outside page one) and Content Decay detection
  (pages whose traffic has meaningfully declined), both surfaced as
  Issues in the same audit flow as every other check.
* **AI Assistant** — plain-language explanations of detected issues,
  generated SEO titles/meta descriptions/image ALT text, an AI-written
  summary of your Fix First action plan, and page-specific Q&A grounded
  in your site's actual detected issues (never invented problems).

= Licensing =

Pro requires an active license, checked via [Freemius](https://freemius.com).
Every unlock above is gated on license validity, not merely on this
plugin being installed — an unlicensed copy behaves identically to Free.
